# Набор для разработки пайплайна

Двенадцать кадров, сгенерированных Nano Banana (Gemini 3 Image) 29.08.2026.

**Чего этот набор НЕ делает.** Он не выносит вердикт по классу A. Вопрос
«держится ли подмена цветности в LAB на настоящем глянце» решается только
настоящими фотографиями: у сгенерированного кадра нет шума матрицы, нет
хроматических аберраций и нет артефактов пересжатия мессенджером — то есть
нет ровно того, что рвёт маски по краям. Вердикт остаётся за тремя реальными
кадрами (01, 02, 03 из этого же списка, снятые телефоном).

**Что он делает.** На нём строятся и отлаживаются гейт качества исходника,
сегментация, композитинг и QA-гейт. Для этого он полностью годится: каждый
кадр покрывает конкретный способ сломаться.

| Файл | Что проверяет |
|---|---|
| `01-silver-sun-reflections` | Светлый исходник, отражения в лаке и стекле. Базовый удачный случай |
| `02-black-crushed-shadows` | **Ключевой.** Отражение белого неба на крышке багажника и крыше при зажатом до черноты низе кузова. Именно здесь подмена a/b оставит небо нейтральным и выдаст «затонированный чёрный» вместо целевого цвета. Плюс запрет направления «тёмное → светлое» |
| `03-underground-parking` | Смешанный искусственный свет, зелёно-жёлтый увод, мало света |
| `04-dusk-mixed-light` | Две цветовые температуры в одном кадре: тёплый фонарь и холодные сумерки |
| `05-overcast-side` | Плоский свет, строгий профиль, мокрый асфальт |
| `06-backlit-sun` | Контровой свет, выбитое небо, кузов в недодержке |
| `07-tinted-glass` | Существующая тонировка: операция умеет только темнее, определение обязательно |
| `08-wheel-silver` | Светлый диск: направление «светлое → тёмное», должно работать |
| `09-wheel-black` | Тёмный диск: детали в тенях между спицами потеряны, маршрут в класс B |
| `10-chrome-grille` | Хром как зеркало — самая частая зона палева |
| `11-snow-white-balance` | Белый кузов на белом снегу, сложный баланс белого, низкий контраст |
| `12-occluded-cluttered` | Соседние машины в кадре и частичное перекрытие: сегментация обязана взять именно ту машину |

Номера на кадрах вымышленные. Автомобили — сгенерированные визуализации,
а не снимки реальных машин; в продукт и в публичные материалы не идут.

## Следующий шаг по набору

Прогнать кадры через имитацию телефонно-мессенджерного тракта — уменьшение,
пересжатие JPEG до q60–75, шум матрицы, субдискретизация цветности. Это
приближает набор к реальности в той части, которая нам и мешает, и остаётся
полностью под нашим контролем, в отличие от случайных настоящих фото.
