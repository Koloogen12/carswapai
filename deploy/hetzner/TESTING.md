# Как проверить YOOMP на стенде руками

Стенд: https://yoomp.io. В базе — посев: сеть JETCAR, две точки, семь
клиентов, три сделки в разных состояниях. Живых людей и живых каналов нет —
и не должно быть, см. [README](README.md) про 152-ФЗ.

## 1 · Войти в кабинет точки

С лендинга — иконка человека справа в шапке, или сразу https://yoomp.io/login.

Вход по почте: адрес → код из письма. Адреса посева — по ролям:

| Кто | Почта | Что открывается |
|---|---|---|
| Владелец точки | owner@jetcar-mytishchi.example | всё: инбокс, CRM, прайс, сотрудники, каналы, учёт |
| Менеджер | manager@jetcar-mytishchi.example | инбокс, CRM, примерка в диалоге |
| Мастер | master@jetcar-mytishchi.example | экран поста, наряды, замер |
| Управляющая компания | network@jetcar.example | панель сети, статусы точек, потолки |

**Код.** Пока в секретах сервера нет `RESEND_API_KEY`, письма не уходят и
вместо кода из письма вводится код стенда — `AUTH_STAND_CODE` из
`/etc/yoomp/secrets.env`, его выдаёт тот, кто держит секреты. На экране код
не показывается: адреса посева лежат в открытом репозитории, и показ кода
означал бы вход для любого. Пять неверных попыток гасят код.

Когда ключ Resend поставлен, код приходит письмом на настоящий адрес — то
есть входить надо своим адресом, заведённым через «Сотрудники» или
приглашение сети. Адреса посева на `.example` писем не получат по построению.

## 2 · Путь точки: от обращения до наряда

1. **Инбокс** `/inbox` — пять обращений из разных каналов. Красная плашка
   сверху — гарантийное обращение, оно вытесняет всё остальное.
2. **Диалог** — открыть любое. Поле ответа живое: Enter отправляет,
   Shift+Enter переносит строку. У обращения из Авито попробовать отправить
   ссылку — отказ «в Авито ссылки не отправляем», это правило канала.
3. **Панель примерки** справа. Если у клиента нет фото — две кнопки:
   «Попросить фото» (уходит с текстом оферты одним сообщением) и «Прислать
   ссылку на гараж». Если фото есть — «Примерить» по артикулу, три света
   уходят всегда все три.
4. **CRM** `/crm` — карточка клиента открывается, воронка по состояниям.
5. **Прайс** `/price` — цену править по строке, артикулы добавлять из
   каталога сети, отключать наличие. Всё сохраняется сразу.
6. **Сотрудники** `/staff` — приглашение по ссылке и QR, увольнение
   отзывает доступ немедленно.
7. **Каналы** `/channels` — форма подключения. Живых аккаунтов Wazzup и
   Авито на стенде нет, дальше формы не пойдёт — и не должно.

## 3 · Путь мастера

1. **Пост** `/bay` — наряд ЗН-2026-0148 в работе. Открыть.
2. **Сверка рулона** — ввести артикул с рулона. Несовпавший блокирует старт
   работ: это МС-3, главная гарантия продукта.
3. **Замер** — из карточки записи. Четыре шага: приезд, обмер по зонам,
   состояние ЛКП с фото, доработки. На последнем — доработки отмечаются,
   итог пересчитывается, две кнопки: «Отправить на согласование» (клиенту в
   ссылку) и «Клиент согласовал голосом» (записывается как устное, с тем, кто
   записал; в наряде видно, что подтверждение не с телефона клиента).

## 4 · Путь клиента

### Гараж — «клиент сам перебирает»
1. https://yoomp.io/g/jetcar-mytishchi — открывается без входа, ноль полей.
2. Артикулы с готовыми кадрами показываются мгновенно, три света.
3. «Показать на своей машине» → экран согласия (два обязательных,
   третий — публикация в примерах — снят по умолчанию) → загрузка фото.
4. **Фото обязано быть с видимым госномером** — спереди или в три четверти.
   Номер закрывается до отправки в модель; на кадре без номера примерка
   честно отказывает с объяснением. Студийные кадры и вид сзади не подойдут.
5. Три примерки в сутки анониму. На четвёртой — экран «крутить дальше
   можно»: оставить телефон → ещё двенадцать, а точка получает лид.
6. Сравнение двух вариантов рядом, «машина уже в плёнке» (+ снятие старой
   из прайса точки), сохранённые сборки живут в ссылке `?set=`.

### Ссылка клиента — «его сделка целиком»
Три конфигурации посева в трёх состояниях:

| Ссылка | Состояние |
|---|---|
| `/c/15500000-0000-4000-8000-000000000006` | выбор подтверждён, ждёт записи на замер |
| `/c/15500000-0000-4000-8000-000000000001` | наряд и счёт, предоплата |
| `/c/15500000-0000-4000-8000-000000000007` | работы сданы, гарантийный талон |

На последней — «Что случилось» → выбрать причину → «Отправить обращение».
Обращение появится в инбоксе точки первой строкой, красным. Повторное
нажатие второго не заводит.

## 5 · Сеть

Войти как управляющая компания → `/network`. Статусы точек — пауза
останавливает новые примерки, отключение закрывает гараж снаружи; переписка
и наряды не трогаются ни в одном статусе. Снятие жёсткого стопа по бюджету —
только отсюда, точка сама не может.

## 6 · Что на стенде работать не будет, и это правильно

| Что | Почему |
|---|---|
| Письмо с кодом | без ключа Resend — вход по коду стенда; с ключом — только на настоящие адреса и только с подтверждённого домена |
| Живые Wazzup и Авито | аккаунтов нет, и подключать их сюда нельзя — это живые клиенты в Германии |
| Примерка на кадре без номера | защита номера: отличить «номера нет» от «не нашёл» нельзя, осторожный выбор единственный |
| Доставка сообщений клиенту | сообщения записываются в переписку, наружу не уходят — канала нет |

## 7 · Если что-то не так

Журнал приложения и воркера на сервере:

```bash
ssh root@167.233.109.195 'docker logs --tail=50 yoomp-app-1; docker logs --tail=50 yoomp-worker-1'
```

Причина отказа примерки — в задании, с техническим текстом:

```bash
ssh root@167.233.109.195 'docker exec yoomp-db-1 psql -U postgres -d yoomp -c "select status, attempts, last_error from render_jobs order by created_at desc limit 5"'
```
