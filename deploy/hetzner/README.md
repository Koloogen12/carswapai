# YOOMP на общем сервере Hetzner — стенд для демо

**Это НЕ боевой контур.** Боевой описан в `../README.md` и живёт в РФ.

## Чем эти два контура различаются и почему

| | `deploy/` (Selectel, РФ) | `deploy/hetzner/` (общий сервер) |
|---|---|---|
| Назначение | боевой контур с персональными данными | стенд для демо и проверки |
| Юрисдикция | РФ | Германия, Falkenstein |
| Персональные данные граждан РФ | можно | **нельзя** |
| Данные в базе | живые клиенты точек | посев и демонстрационные сделки |

Ст. 18 ч. 5 152-ФЗ требует, чтобы запись, систематизация и хранение
персональных данных граждан РФ шли в базах на территории РФ. Юрлицо проекта
зарегистрировано как оператор ПД. Имя, телефон, переписка и фотография
машины с читаемым госномером — это персональные данные.

Поэтому: **как только на yoomp.io заходит первая живая точка со своими
клиентами, база обязана быть в РФ.** До этого момента стенд с посевом
законен, и он же нужен, чтобы показывать продукт.

Практическое следствие для того, кто это читает: не восстанавливай сюда дамп
боевой базы и не подключай сюда живые каналы Wazzup и Авито. Обращение
клиента, пришедшее в этот контур, — уже нарушение.

## Что здесь лежит

| Файл | Что делает |
|---|---|
| `compose.stack.yml` | стек: база, накат миграций, приложение, воркер |
| `deploy.sh` | выкатка и обновление; запускается на сервере |
| `caddy-block.sh` | дописывает свой блок в общий Caddyfile |
| `init/01-roles.sh` | роли Postgres при первичной инициализации кластера |

## Выкатка

```bash
ssh root@167.233.109.195 'bash -s' < deploy/hetzner/deploy.sh
ssh root@167.233.109.195 'bash -s' < deploy/hetzner/caddy-block.sh
```

Повторный запуск — обычный способ обновиться: секреты не перегенерируются,
блок Caddy не дублируется, миграции идут по одному разу.

## Что на этом сервере трогать нельзя

Машина общая, на ней живут ещё два продукта. Всё, что выходит за пределы
`/opt/stacks/yoomp`, `/etc/yoomp` и собственного блока в Caddyfile, — это
авария у соседа, а не у нас.

Запрещено без согласования: `docker system prune`, `docker volume prune`,
`docker network rm edge`, перезапись Caddyfile целиком,
`docker restart caddy-caddy-1`, изменения `ufw`, правка общего
`/opt/backups/dump-all.sh`.

Разрешённая уборка ровно одна:
`docker builder prune -f --filter until=168h`.
